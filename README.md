# 📊 Exercícios com Vetores e Laço For — JavaScript

Exercícios práticos de JavaScript focados em manipulação de arrays com laço `for`, desenvolvidos durante o curso **MaisPraTi**.

---

## 📁 Estrutura do Projeto

```
exercicios/
├── exercicio1.js   # Acumulando valor de vendas
├── exercicio2.js   # Calculando média de notas
├── exercicio3.js   # Procurando um valor no array
└── exercicio4.js   # Contagem de números pares
```

---

## 📝 Exercícios

### Exercício 1 — Acumulando Valor de Vendas
Calcula o total de vendas de uma loja a partir de um array com os valores das transações diárias.

**Conceitos praticados:**
- Declaração de arrays
- Laço `for` com `array.length`
- Acumulador inicializado com `0`

---

### Exercício 2 — Calculando Média de Notas
Calcula a média das notas de um/a estudante a partir de um array de notas.

**Conceitos praticados:**
- Soma acumulada com `for`
- Cálculo de média (`total / array.length`)

---

### Exercício 3 — Procurando um Valor no Array
Verifica se um número específico existe dentro de um array, exibindo "Número encontrado" ou "Número não encontrado".

**Conceitos praticados:**
- Variável booleana (`true` / `false`)
- `if` dentro do `for` para comparação
- Operador de igualdade estrita `===`

---

### Exercício 4 — Contagem de Números Pares
Conta quantos números pares existem em um array.

**Conceitos praticados:**
- Operador módulo `%`
- Contagem com incremento `++`
- Condição `% 2 === 0` para verificar paridade

---

## ▶️ Como Executar
